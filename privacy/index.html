الجهة المسؤولة

ناشر الموقع: علي محمد. للأسئلة العامة، استخدم صفحة GitHub Issues عبر صفحة الدعم. هذه قناة عامة؛ لا تشارك بيانات شخصية حساسة. للاستفسارات التي تتطلب خصوصية، اطلب قناة تواصل خاصة برسالة عامة لا تتضمن بياناتك الحساسة.

ما الذي نعالجه في الموقع؟

الصفحات الحالية لا تضم حسابات مستخدمين أو نماذج أو تحليلات يضيفها الناشر أو ملفات تعريف ارتباط يضعها كود الموقع. اختيار اللغة وتصفية البطاقات يتمّان داخل المتصفح دون إرسال مدخلات إلى خادم خاص بنا.

الاستضافة على GitHub Pages

يُستضاف الموقع على GitHub Pages، وقد تجمع GitHub عناوين IP وبيانات تقنية للزوار وفق سياستها. لا نتحكم في مدة احتفاظ GitHub بهذه السجلات.

روابط خارجية

قد تقود بعض الروابط إلى GitHub أو منصات أخرى لها سياسات مستقلة. لن تُضاف أدوات تتبع أو تحميل من شبكات خارجية إلى هذا الموقع دون تحديث هذا البيان.

الإضافات المستقبلية والحقوق

GitHub Issues خدمة عامة منفصلة؛ قد تظهر أسماء حسابات المشاركين ومحتويات البلاغات علناً وتخضع لسياسة GitHub. لا يجمع الموقع نفسه بيانات الحسابات عبر نماذج. ستُراجع معالجة البيانات وسياسات كل إضافة على حدة قبل نشرها.
