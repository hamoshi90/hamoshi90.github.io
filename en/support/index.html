How will support work?

Report website or tool issues and suggestions using the public GitHub Issues tracker for this website. You need a GitHub account, and submissions are public. Do not attach confidential data.

What should a report include?

Tool name and version, steps to reproduce, operating system, and sanitized errors without passwords, tokens or personal information.

Reporting security issues

Do not publish vulnerability details or credentials in public GitHub issues. For sensitive issues in downloadable source, request a private channel without posting exploit details or customer information.
