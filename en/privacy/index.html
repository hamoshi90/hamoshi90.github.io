Who is responsible?

Website publisher: Ali Mohammad. Use the GitHub Issues link on the support page for general queries. Issues are public; do not include sensitive personal information. For private matters, request a private contact channel with a non-sensitive public issue.

What does the website do?

The current pages provide no account registration, forms, publisher-managed analytics or cookies set by the site's code. Language switching and catalog filtering run inside your browser without sending their inputs to a server we operate.

GitHub Pages hosting

If hosted on GitHub Pages, GitHub logs visitors' IP addresses for security purposes and may process other technical data under its own privacy policy. We cannot specify the provider's retention period for these logs.

External links

Some links lead to GitHub or other services, whose privacy policies apply. Any future trackers or third-party assets will require updating this notice.

Future plugins and data rights

GitHub Issues is a separate public service; usernames and report contents can be publicly visible and are governed by GitHub's policy. No site registration or publisher-operated form collects account data. Each downloadable tool has a separate privacy notice; future Plugin Directory submissions are assessed separately.

Free source downloads

ZIP files and checksums are served by GitHub Pages; GitHub may log download requests, IP addresses and technical data under its policies. This static site does not collect publisher payment or login details. Files uploaded by users to ChatGPT or other tools are handled under those providers' policies.
