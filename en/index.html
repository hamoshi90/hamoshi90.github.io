Our process 02

Share openly, release responsibly.

Public distribution is a separate choice for each release. Private code and sensitive tools stay private until reviewed.

01 — Confirm rights

Check licensing rights, third-party dependencies and notices.

02 — Verify security

Review secrets and sensitive behavior; test the tool's real limits.

03 — Publish clearly

Announce the version, license and working links once officially approved.

2.0
OPEN SOURCE, WITH CARE

Open work, clear ownership.

We aim to use Apache 2.0 for original components the publisher is entitled to license. Each version's LICENSE and NOTICE files govern its distribution.

FAQs 03

Before you begin

Can I install the tools now?+

This is a preview of the catalog. Verified public install links will be added only after official publication.

Are these tools free to use?+

The goal is to distribute eligible original code under Apache 2.0. Some tools may need external services or build environments with their own pricing or terms.

Does this expose private project data?+

No private project source or secrets are presented on this site. Each release must pass its own review before going public.
