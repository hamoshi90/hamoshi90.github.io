# Security reports

**Do not post private keys, access tokens, exploit payloads, or sensitive vulnerability details in public GitHub Issues.**

If this repository has **private vulnerability reporting** enabled, use the GitHub Security advisory reporting flow to submit confidential details.

If private reporting is unavailable, open a general, non-sensitive issue asking the maintainer for a private contact path, **without** describing the vulnerability or including personal information.

This site is a static catalog only. Vulnerabilities in separately released plugins should be disclosed through the method provided by the corresponding project.
