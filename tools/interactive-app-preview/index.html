Installation and verification guide ↗

What it does

Read available source theme files, CSS, screen structure and original icons, then prepare a clickable browser preview. Audit source color overlap, Arabic RTL structure and offline simulation boundaries.

Inputs and outputs

Theme sources, styling files, screenshots or supplied app projects. Outputs include a reviewable prototype, theme evidence, interaction notes and fidelity differences.

Important limitations

Browser previews are not native Android runtime tests or verified pixel-identical screenshots. Without source theme evidence, exact app colors cannot be claimed. Mock actions must never initiate real transactions.

Availability

These source ZIPs are independently downloadable for free. The ChatGPT Plugin Directory release has not been submitted or approved. Eligible ChatGPT accounts may allow individual skill ZIP uploads; optional external services may have their own charges.
