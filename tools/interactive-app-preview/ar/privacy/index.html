البيئة والخدمات الخارجية

قد تستعمل المستودعات أو استضافة المعاينات أو أدوات اختبار المتصفح عند اختيار المستخدم، وفق سياسات تلك الخدمات.

التخزين والاحتفاظ

لا تتضمن حزمة المهارات هذه خادمًا تابعًا للناشر أو حسابات مستخدمين أو شيفرة لتتبع الاستخدام لصالحه. قد تُحفظ الملفات والتقارير في بيئة تشغيل ChatGPT أو GitHub أو خدمة اختارها المستخدم، ولكل منها سياسة احتفاظ مستقلة. لا نتحكم في حذف تلك السجلات.

تجنب المعلومات الحساسة

لا تُدخل كلمات المرور أو الرموز أو مفاتيح التوقيع أو سجلات العملاء الفعلية أو بيانات مالية خاصة في مواد الدعم العامة. استخدم بيانات تجريبية منقحة متى أمكن. GitHub Issues خدمة علنية وقد تظهر فيها أسماء المستخدمين ومحتوى البلاغات.

الاستفسارات والحقوق

اطرح استفسارًا عامًا عبر صفحة الدعم دون مشاركة بيانات سرية، واطلب وسيلة خاصة إذا كانت المسألة حساسة. راجع سياسات المنصات التي تستخدمها لإدارة بياناتها وطلب حذفها.
