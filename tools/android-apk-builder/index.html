Android APK Builder — Overview

Build preparation and signed APK validation using tools that are actually available.

Android build & verification

Package status

النسخة العربية

What it does

Inspect Android projects, coordinate Gradle or Flutter debug builds, and validate APK structure, SHA-256 and cryptographic signatures. It can prepare an authorized GitHub Actions workflow where local Android tooling is missing.

Inputs and outputs

Projects supplied by the user, project build metadata and test artifacts. Results may include sanitized build diagnostics, integrity hashes and signing verification reports.

Important limitations

The skill does not ship the Android SDK, compile APKs without a toolchain, produce private signing keys or publish applications automatically. A valid APK signature does not replace device or emulator testing.

Availability

This is an offline public-submission candidate; it has not been uploaded for official review or made publicly installable. The skill itself has no publisher fees, but external execution environments may have separate charges.
