How the skill and separately authorized tools may handle your task data.

النسخة العربية

Data that may be processed

Android source files, ZIP archives, build manifests, APK files, diagnostic logs and public signing-certificate fingerprints provided for the task.

Execution and external services

Gradle, Flutter, Android SDK, GitHub Actions or artifact stores may be used only when separately available and authorized. Build dependencies may be downloaded by those services; their own processing policies apply.

Storage and retention

The skills-only package has no publisher-operated server, account database or code for publisher analytics. Working files and reports can be stored in ChatGPT's execution environment or an authorized external provider. Those platforms control retention and deletion; the publisher does not control their records.

Avoid sensitive information

Do not submit passwords, bearer tokens, private signing keys, production logs, real customer records or private financial data in public support channels. Prefer synthetic or redacted fixtures. GitHub Issues is public and may expose usernames and issue contents.

Questions and rights

For non-sensitive questions use the public support page; request a private contact route before discussing confidential matters. Exercise data rights through the respective platforms for records they control.
