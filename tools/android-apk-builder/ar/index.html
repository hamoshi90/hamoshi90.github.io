بناء أندرويد والتحقق

حالة الحزمة

مرشح محلي للإصدار 1.0.2. لا يوجد رابط تثبيت عام معتمد.

English version

ماذا تقدّم؟

تفحص المهارة مشاريع Android، وتساعد على بناء نسخ اختبارية باستخدام Gradle أو Flutter، والتحقق من بنية APK وبصمته الرقمية وتوقيعه. ويمكنها إعداد سير عمل GitHub Actions مصرح به عند غياب أدوات البناء محليًا.

المدخلات والمخرجات

مصادر المشاريع التي يقدمها المستخدم وملفات إعداد البناء وحزم الاختبار. تشمل النتائج سجلات أخطاء منقحة وبصمات سلامة وتقارير التحقق من التوقيع.

الحدود المهمة

لا تحتوي المهارة على Android SDK، ولا تُنشئ APK دون بيئة بناء مناسبة، ولا تولّد مفاتيح توقيع خاصة أو تنشر التطبيقات تلقائيًا. صحة التوقيع لا تعني اجتياز اختبارات جهاز حقيقي.

حالة الإتاحة

الحزمة مرشح محلي للتقديم العام. لم تُرفع بعد للمراجعة الرسمية ولم تصبح متاحة للتثبيت العام. لا تتطلب الحزمة دفعًا أو اشتراكًا للناشر، لكن بيئات التشغيل الخارجية قد تكون مدفوعة.
