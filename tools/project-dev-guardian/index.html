About the skill

Code review and release-safety guidance. No automatic publishing or financial operations.

النسخة العربية

What it does

Guides source inspections for ZIPs, folders and authorized GitHub repositories; captures baselines, checks common syntax and sensitive-file risks, and prepares structured review reports. Its included Python preflight script works without external dependencies.

Boundaries

A heuristic scan is not a security certification. The skill does not independently deploy apps, access private repositories, run external analyzers without installing them, perform money transfers or guarantee production readiness.

Availability
