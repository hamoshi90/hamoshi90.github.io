Project Dev Guardian — حارس المشاريع

مهارة لمراجعة الشيفرة ومخاطر الإصدارات من إعداد علي محمد؛ الإصدار العام ما زال قيد المراجعة.

SKILL / 2026

عن الإضافة

إرشادات لمراجعة المشروعات وصيانة الإصدارات بأمان. لا توجد عمليات نشر أو مالية تلقائية.

English version

ما الذي تقدمه؟

تساعد على مراجعة ملفات ZIP والمجلدات ومستودعات GitHub المصرّح بها، وتوثيق خطوط الأساس، وفحص صياغة Python وJSON ومؤشرات الأسرار، وإنتاج تقرير مراجعة منظم. تتضمن أداة فحص أولي بلغة Python دون مكتبات خارجية.

حدود العمل

الفحص الأولي ليس شهادة أمنية. لا تتصل المهارة تلقائياً بالمستودعات الخاصة، ولا تنشر التطبيقات أو تنفّذ عمليات مالية أو تضمن جاهزية الإنتاج. بعض الاختبارات المتقدمة تتطلب أدوات مثبتة وتفويضاً مناسباً.

التوفر

الإضافة العامة قيد التجهيز؛ لا يوجد رابط تثبيت عام متحقق منه بعد. تخضع الإتاحة لمراجعة المنصة.

الناشر

علي محمد. الترخيص المستهدف للمصدر الذي يملك حقوقه هو Apache 2.0، مع احترام تراخيص الأدوات الخارجية.
