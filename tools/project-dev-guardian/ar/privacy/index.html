Project Dev Guardian — سياسة الخصوصية

بيان خصوصية مهارة Project Dev Guardian، وهو مستقل عن سياسة الموقع التعريفي العامة.

SKILL / 2026

عن الإضافة

إرشادات لمراجعة المشروعات وصيانة الإصدارات بأمان. لا توجد عمليات نشر أو مالية تلقائية.

English version

البيانات المحتمل التعامل معها

عند تشغيل المهارة قد تُراجع ملفات مصدر أو أرشيفات ZIP أو بيانات مستودعات صرّح المستخدم بالوصول إليها، بما فيها أسماء المسارات ومقتطفات الشيفرة وسجلات الأخطاء. تنتج أداة الفحص الأولي أسماء ملفات وقواعد تحذير وملاحظات دون كشف قيم الأسرار المكتشفة.

مَن يعالج البيانات؟

لا تتضمن حزمة المهارة فقط خادماً للناشر أو حساب مستخدم أو واجهة إرسال قياس عن بُعد، ولا تنفذ أداة الفحص المرفقة اتصالاً شبكياً. قد تعالج ChatGPT أو أدوات GitHub وغيرها التي فعّلها المستخدم بيانات المهمة وفق شروطها الخاصة. تجنب إدخال أسرار أو بيانات عملاء الإنتاج.

التخزين والاحتفاظ

لا ترفع أداة الفحص التقرير تلقائياً إلى خادم خاص بالناشر. عند استخدام خيار --output يحفظ التقرير في مسار تحدده بيئة التنفيذ. تعتمد مدة الاحتفاظ ببيانات ChatGPT وGitHub والخدمات الأخرى على سياساتها وإعداداتها التي لا يتحكم بها ناشر المهارة.

الدعم والحقوق

يمكن إرسال الأسئلة العامة غير الحساسة عبر GitHub Issues. البلاغات وأسماء أصحابها علنية؛ لا تنشر بياناتك الشخصية أو أسرارك. للطلبات الخاصة اطرح سؤالاً عاماً للحصول على وسيلة تواصل خاصة دون مشاركة تفاصيل حساسة.
