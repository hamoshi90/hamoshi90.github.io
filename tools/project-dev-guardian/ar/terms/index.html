شروط وترخيص مهارة Project Dev Guardian المحددة، منفصلة عن شروط الموقع التعريفي.

SKILL / 2026

عن الإضافة

إرشادات لمراجعة المشروعات وصيانة الإصدارات بأمان. لا توجد عمليات نشر أو مالية تلقائية.

English version

الترخيص

يُعتزم توزيع الأجزاء الأصلية التي تثبت حقوق ترخيصها بموجب Apache License, Version 2.0 عند اعتماد الإصدار العام. الأدوات الخارجية المذكورة كمراجع ليست ضمن هذه الحزمة ولا تصبح مرخصة تلقائياً بالترخيص نفسه.

إخلاء الضمان

توفر المهارة إرشاداً وفحوصاً استدلالية، ولا تعد تقاريرها دليلاً قاطعاً على سلامة الشيفرة أو جاهزية الإنتاج أو الامتثال. تحقق من النتائج واختبر التغييرات والصلاحيات قبل التطبيق.

التشغيل والخدمات الخارجية

قد تتطلب الإجراءات المتقدمة اتصال GitHub مصرحاً به أو أدوات مستقلة وشروطاً أو رسومًا خاصة بها. الحزمة لا توفر خادماً خاصاً للتنفيذ ولا تضمن بناء APK.

الاستخدام المسؤول والدعم

افحص فقط المشاريع التي تملكها أو لديك تفويض بفحصها. لا تنشر الأسرار أو شيفرة المشاريع الخاصة أو تفاصيل الثغرات في Issues العامة. استخدم صفحة الدعم للبلاغات غير الحساسة.
