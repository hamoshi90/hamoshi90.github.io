About the skill

Code review and release-safety guidance. No automatic publishing or financial operations.

النسخة العربية

What the skill can process

When invoked, the workflow may inspect source files, ZIP archives, repository metadata, code snippets, file paths and error logs supplied or explicitly connected by the user. Its read-only preflight script produces file names, rule identifiers and warning summaries; it intentionally redacts suspected credential values.

Who receives it

The submitted skills-only package defines no publisher-operated server, user account or telemetry endpoint and contains no networking logic in its bundled scan script. ChatGPT and any user-authorized GitHub or other third-party tools involved in a task may process relevant content under their own terms. Do not upload credentials or production customer data.

Storage and retention

The preflight script does not automatically upload data or retain it in a publisher database. If the user supplies --output, the report is saved to a location selected in the execution environment. ChatGPT, GitHub, hosting and other connected services have their own storage, retention and deletion controls; this publisher does not control those records.

Support and your rights

For public, non-sensitive questions, use the GitHub Issues support page. Issues and usernames can be publicly visible; never post secrets or personal information. For confidential requests, open a non-sensitive inquiry asking for a private contact method before sharing details.
